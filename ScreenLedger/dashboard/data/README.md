# Saved District dashboard data

## Hourly snapshots

`district_hourly_runs_2026-11-07/` contains the two saved District city-feed snapshots. `run_summaries.json` is the aggregate source for the overview. The two `unique_screenings_*.csv` files contain one row per deduplicated session; the `city_coverage_*.csv` files distinguish captured, failed, and not-collected city feeds. CSV remains Excel-readable.

`matched_delta_2026-11-07_0100_0200.json` is generated by `../compare_hourly_snapshots.py`. It matches future screenings across the two captures by movie, venue, showtime, and capacity; it separates positive booked-plus-blocked seat changes from releases/corrections and new or disappeared sessions. The run interval and coverage differences are part of the output. Confirmed-revenue change remains null unless every matched session has complete pricing.

## City label to state/UT reference

`city_state_mapping_2026-11-07.csv` preserves every selector label, including duplicates. Its source is District's visible public movie location selector and the official Census of India 2011 Location Code Directory. The builder uses exact normalized town-name matching, then allows an exact settlement-name fallback only when all matching records point to one current state/UT. Multiple-state matches and no-match labels stay unassigned; there is no fuzzy matching. Curated spelling/state-split aliases are labeled separately in the `mapping_status` and `mapping_basis` columns.

This file maps a **District selector label** to a likely state/UT for coverage exploration only. It does not map cinemas to states. District city feeds can contain cinemas outside the feed's named city, and selector aliases or spelling can differ. Do not use this file to allocate screening totals, occupancy, bookings, or confirmed revenue by state.

Sources:

- [Census 2011 Location Code Directory catalog](https://censusindia.gov.in/nada/index.php/catalog/42648)
- [Census 2011 Location Code Directory workbook](https://censusindia.gov.in/nada/index.php/catalog/42648/download/46323/PC11_TV_DIR.xlsx)
- [Ministry of Panchayati Raj: current Local Government Directory](https://panchayat.gov.in/en/lgd/)
- [Open Government Data: current LGD catalog](https://data.gov.in/catalog/local-government-directory-lgd)
- [District movies and location selector](https://www.district.in/movies/)
- [Open Government Data: Complete Towns Directory](https://data.gov.in/catalog/complete-towns-directory-indiastatedistrictsub-district-level-census-2011)

The 2011 directory predates some current administrative boundaries and spellings. The provenance JSON records match counts and limitations. The source workbook is an input to the builder and is intentionally not part of this project folder or repository.
