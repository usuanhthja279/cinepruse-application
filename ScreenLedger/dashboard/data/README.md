# Saved District dashboard data

## Hourly snapshots

`district_hourly_runs_2026-11-07/` contains the four saved District city-feed snapshots from 01:00 through 04:00 IST. `run_summaries.json` is the aggregate source for the overview and selector. Each `unique_screenings_*.csv` contains one row per deduplicated session; each `city_coverage_*.csv` distinguishes captured, failed, and not-collected city feeds. CSV remains Excel-readable.

The `matched_delta_*.json` files are generated by `../compare_hourly_snapshots.py` for consecutive hourly pairs. They match future screenings by movie, venue, showtime, and capacity; separate positive booked-plus-blocked seat changes from releases/corrections and new or disappeared sessions; and record each run interval and coverage difference. Confirmed-revenue change remains null unless every matched session has complete pricing. The UI's tickets-sold chart uses the positive matched-session changes and displays releases/corrections separately; new coverage is excluded.

## City label to state/UT reference

`city_state_mapping_2026-11-07.csv` preserves every selector label, including duplicates. Its source is District's visible public movie location selector and the official Census of India 2011 Location Code Directory. The builder uses exact normalized town-name matching, then allows an exact settlement-name fallback only when all matching records point to one current state/UT. Multiple-state matches and no-match labels stay unassigned; there is no fuzzy matching. Curated spelling/state-split aliases are labeled separately in the `mapping_status` and `mapping_basis` columns.

This file maps a **District selector label** to a likely state/UT; it does not verify cinema locations. The day-ledger map uses city names found in cinema names only as explicitly labeled candidates, never the feed city. Conflicting and unmatched venue names stay unassigned; download the cinema mapping review for the matched city names and candidate states. Inferred totals can be wrong and must not be represented as verified state sales.
